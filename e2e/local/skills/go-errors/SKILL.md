# Обработка ошибок в Go

1. Ошибку нельзя игнорировать (`_ =`, `x, _ :=`), кроме явно безвредных случаев
   с комментарием, почему.
2. Оборачивай с контекстом: `fmt.Errorf("get user %s: %w", id, err)`; сравнивай
   через `errors.Is` / `errors.As`, а не строками.
3. Наружу (в HTTP-ответ) не отдавай текст внутренних ошибок: логируй их, клиенту —
   общее сообщение и корректный статус.
4. `defer rows.Close()` сразу после успешного `Query`; проверяй `rows.Err()`.
5. Ошибка публикации события после записи в БД — не повод отвечать 500 без
   компенсации: опиши, что произойдёт с уже созданной записью.
