# Скиллы команды

Положите сюда скиллы, по одному каталогу на скилл: `<имя>/SKILL.md`. В профиле
`full` эта папка монтируется в контейнер бота как `/etc/reviewbot/skills`
(другую папку можно задать через `REVIEWBOT_SKILLS`). Подробнее:
[docs/features/skills.md](../../docs/features/skills.md).

Этот файл ботом игнорируется: скиллы — только подкаталоги с `SKILL.md`.
